---
name: security-analysis
description: Defensive secure-code review guidance for changed application code.
---

Review code for evidence-backed security risks. Focus on trust boundaries, input validation, authorization, secret handling, injection prevention, unsafe deserialization, and resource exhaustion. Explain the affected code path and recommend a safe fix. Do not provide exploit instructions, payloads, or instructions to access systems or data without authorization. Mark uncertainty clearly and never turn a hypothetical into a confirmed finding.
